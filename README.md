# Artalyze

Artalyze is a daily visual guessing game where you try to figure out which painting was made by a human and which was generated by AI. It's inspired by the simplicity of games like Wordle, but focuses on creative intuition.

🟢 The app is fully live and available at: www.artalyze.app

Each day, you'll see 5 image pairs — your goal is to pick the human-made one in each pair. Results are tracked, and stats like streaks and win percentage keep things fun and competitive.

## What It Does

- 5 new image pairs every day at midnight (EST)
- Guess which is human-made for each pair
- Tracks stats: win %, streaks, guess distribution
- Login with email + OTP (no password needed)
- Internal tools for uploading and managing puzzles

## Tech Stack

### Frontend:
- React
- Tailwind CSS
- Swiper.js
- Axios

### Backend:
- Node.js + Express
- MongoDB Atlas
- JWT Auth
- AWS SES (for OTP login emails)
- Cloudinary (for image storage)
